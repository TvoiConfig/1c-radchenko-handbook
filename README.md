# 1С: учебный проект по «Практическому пособию разработчика»

Учебная конфигурация на платформе **1С:Предприятие 8** — прикладное решение для небольшой фирмы, оказывающей бытовые услуги: учёт материалов, оказание услуг клиентами, продажи, цены и отчётность.

Проект выполнен по книге: *Радченко М. Г., Хрусталева Е. Ю. «1С:Предприятие 8.3. Практическое пособие разработчика. Примеры и типовые приемы», 2023*. 

> Это учебный проект, а не коммерческая разработка. Структура предметной области взята из книги, конфигурация разработана в течении прочтения книги.

---

## Что умеет конфигурация

- Ведёт справочники клиентов, сотрудников (мастеров), складов и номенклатуры (материалы и услуги в одной иерархии).
- Оформляет **приходные накладные** на материалы и документы **«Оказание услуги»** (клиент, мастер, склад, перечень номенклатуры).
- При проведении документов пишет движения в регистры: остатки и стоимость материалов, продажи.
- Списывает материалы по **средней стоимости** и **не даёт провести документ, если материала не хватает** (контроль остатков в оперативном режиме).
- Подставляет розничную цену из периодического регистра сведений на дату документа.
- Позволяет описывать материалы произвольными свойствами (цвет, производитель и т. д.) и вести остатки в разрезе этих свойств.
- Формирует печатную форму документа «Оказание услуги».
- Содержит набор отчётов на системе компоновки данных (СКД).

## Модель данных

| Тип                              | Объект                                                  | Назначение                                                                                               |
| -------------------------------- | ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Справочник                       | `Номенклатура` (иерархический)                          | материалы и услуги; реквизит `ВидНоменклатуры` (перечисление), своё представление через модуль менеджера |
| Справочник                       | `ВариантыНоменклатуры`                                  | подчинён номенклатуре                                                                                    |
| Справочник                       | `ДополнительныеСвойстваНоменклатуры`                    | значения свойств; владелец — план видов характеристик                                                    |
| Справочник                       | `Клиенты`, `Склады` (предопределённый склад «Основной») |                                                                                                          |
| Справочник                       | `Сотрудники`                                            | табличная часть `ТрудоваяДеятельность` (организация, начало/окончание работы, должность)                 |
| Перечисление                     | `ВидыНоменклатуры`                                      | `Материал`, `Услуга`                                                                                     |
| План видов характеристик         | `СвойстваНоменклатуры`                                  | пользовательские свойства материалов с произвольным типом значения                                       |
| Документ                         | `ПриходнаяНакладная`                                    | поступление материалов на склад                                                                          |
| Документ                         | `ОказаниеУслуги`                                        | услуги клиенту, расход материалов, выручка                                                               |
| Регистр накопления (остатки)     | `ОстаткиМатериалов`                                     | количество материалов по складу и набору свойств                                                         |
| Регистр накопления (остатки)     | `СтоимостьМатериалов`                                   | стоимость материалов                                                                                     |
| Регистр накопления (обороты)     | `Продажи`                                               | выручка, количество, себестоимость по клиенту, мастеру, номенклатуре                                     |
| Регистр сведений (периодический) | `Цены`                                                  | розничная цена номенклатуры по датам                                                                     |
| Регистр сведений                 | `ЗначениеСвойствНоменклатуры`                           | значения свойств для наборов свойств                                                                     |
| Общий модуль                     | `РаботаСДокументами`, `РаботаСоСправочниками`           | расчёт суммы строки, получение розничной цены                                                            |

## Отчёты

| Отчёт | Источник данных |
|---|---|
| Материалы | остатки и обороты материалов по складам |
| Остатки материалов по свойствам | остатки и обороты в разрезе наборов свойств |
| Перечень услуг | номенклатура + срез последних цен, параметры отчёта |
| Реестр документов «Оказание услуги» | документы по складу, мастеру, клиенту |
| Рейтинг клиентов | обороты продаж, вычисляемое поле «Доход» |
| Рейтинг услуг | обороты продаж по услугам, сортировка по убыванию выручки |
| Выручка мастеров | обороты продаж по дням в разрезе мастеров |
| Универсальный | свободный отчёт по регистру продаж |
